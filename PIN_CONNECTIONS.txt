2. POWER DISTRIBUTION SCHEMATIC (DUAL VOLTAGE)
-------------------------------------------------------------------------------

230V AC Grid Power
   │
   ▼
[ 12V 10A DC PSU ]
   │
   ├───────► 12V DC Main Positive Bus (+)
   │            │
   │            ├──────► Relay Module COM Terminals (COM 1 to COM 6)
   │            │
   │            └──────► (Do NOT connect 12V directly to ESP32!)
   │
   ├───────► 12V DC Main Negative Bus (-) / GND
   │            │
   │            ├──────► Pump 1 to 5 Negative (-) Terminals
   │            ├──────► Stirrer Motor Negative (-) Terminal
   │            └──────► Buck Converter 12V GND IN
   │
   ▼
[ 12V to 5V DC Buck Step-Down Converter ]
   │
   ├───────► Regulated 5V DC Positive Bus (+)
   │            │
   │            ├──────► ESP32 VIN / 5V Pin
   │            ├──────► 5-Channel Relay Module VCC
   │            ├──────► 16x2 I2C LCD VCC Pin
   │            └──────► IR Cup Sensor VCC Pin
   │
   └───────► Common Ground (GND) Bus (-)
                │
                ├──────► ESP32 GND Pin
                ├──────► Relay Module GND Pin
                ├──────► 16x2 I2C LCD GND Pin
                └──────► IR Cup Sensor GND Pin

-------------------------------------------------------------------------------
4. SENSOR & DISPLAY DETAILED WIRING
-------------------------------------------------------------------------------

A. 16x2 I2C LCD Display (PCF8574 Backpack)
   - GND  -->  ESP32 GND / Common GND
   - VCC  -->  5V Output (Buck Converter)
   - SDA  -->  ESP32 GPIO 21
   - SCL  -->  ESP32 GPIO 22

B. IR Cup Proximity Sensor
   - GND  -->  ESP32 GND / Common GND
   - VCC  -->  5V Output (Buck Converter)
   - OUT  -->  ESP32 GPIO 4 (Internal Pull-Up Enabled)


-------------------------------------------------------------------------------
5. SAFETY & TROUBLESHOOTING NOTES
-------------------------------------------------------------------------------

1. Active LOW Logic: Relay channels trigger ON when GPIO pin is set to LOW (0V).
   If your relay module is Active HIGH, change `#define RELAY_ACTIVE_LOW false`
   in `Config.h`.

2. Ground Sharing: The 12V PSU negative terminal and the 5V Buck converter 
   ground MUST be tied to the same Common Ground bus.

3. Flyback Diode: Most 12V relay modules include optocouplers and flyback diodes.
   If using custom MOSFETs or individual relays, place a 1N4007 diode across
   pump motor terminals to eliminate inductive kickback voltages.
